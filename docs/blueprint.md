# **App Name**: WattWatcher AI

## Core Features:

- Home Configuration: User input screens for home size (1BHK, 2BHK), number of rooms, and appliances.
- Usage Settings: Input screens for average daily usage hours per device and monthly electricity bill goal (₹ or $), using toggles and sliders.
- Appliance Input: Form to add new appliances: Device Name, Room, Estimated Daily Usage (hrs), Status (On/Off toggle).
- Intelligent Reminders: AI tool analyzes user inputs to set default reminder rules (e.g., geyser on > 30 mins).
- Energy Prediction: AI tool predicts daily and monthly energy usage based on appliance usage and user goals.
- Personalized Tips: AI tool generates custom energy-saving tips based on user data and usage patterns.
- Real-Time Feedback: Dynamic input-based cards update based on appliance usage and room behavior (e.g., 'Bedroom fan running over usual 2 hrs').

## Style Guidelines:

- Primary color: Electric blue (#007BFF) for a modern and energetic feel, reminiscent of electricity.
- Background color: Soft dark gray (#222222) for a professional, minimal, and modern look.
- Accent color: Lime green (#BFFF00) for highlights and call-to-action elements to create contrast and reinforce the 'energy saving' theme.
- Body and headline font: 'Inter', a sans-serif with a modern, neutral look suitable for both headlines and body text.
- Use minimalist icons for each appliance (fan, TV, AC, etc.) to aid quick recognition.
- Clean, grouped sections and labeled fields on user input pages for ease of use. Rounded cards and soft shadows for a modern UI.
- Subtle animations for save button confirmations and toast notifications to provide user feedback.
